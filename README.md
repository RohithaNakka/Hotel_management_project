Hotel Management Project – EDA (Exploratory Data Analysis)
📋 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on hotel management data using SQL. The main goal is to extract meaningful insights about guests, bookings, revenues, and trends from the hotel’s operational database.

The dataset primarily contains two key tables:

Guest_List — stores guest details such as name, city, and guest ID.

Booking — stores booking information such as booking ID, amount, check-in/check-out dates, and guest ID.

🧩 Objective

To understand the booking behavior, revenue generation, and guest demographics through SQL-based EDA.

Key areas analyzed:

Guest ranking based on the number of bookings and total amount paid.

Total revenue generated.

Booking activity during a specific date range.

Average stay duration of guests.

Top-spending guests.

Cities contributing the most guests.
